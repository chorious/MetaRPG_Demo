## 3. Performance Regression Analysis

### Symptom
Average turn wall time increased from **~20s** (v0.7.4) to **~40s** (v0.7.5).

### Root Cause

**L2 semantic judge call volume increased by ~5-10x per turn.**

v0.7.4 `_is_risk_turn` covered only hidden truth / hook change / canon (~10-20% of turns, 2 judge calls each).

v0.7.5 `_is_l2_required` covers 9 conditions (~80%+ of turns), and each required turn now runs **4 serial LLM calls**:

```python
# post_render_checker.py:78-179
if l2_required:
    # 1. hidden_truth_exposure  → LLM roundtrip 1
    # 2. render_claim_support   → LLM roundtrip 2
    # 3. intent_fulfillment     → LLM roundtrip 3
    # 4. object_personification → LLM roundtrip 4 (conditional)
```

Each call is a local vLLM roundtrip (`192.168.50.20:8101`). At ~3-5s per call, 4 serial calls = 12-20s of L2 overhead alone.

Additionally, the **repair loop** (`runner.py:888-913`) re-runs `check_rendered_prose` on repair failure, potentially adding another 4 LLM calls.

| Scenario | v0.7.4 LLM calls/turn | v0.7.5 LLM calls/turn |
|---|---|---|
| Average | ~0.3-0.6 | ~2.5-3.5 |
| With repair | ~0.3-0.6 | ~5-7 |

### Proposed Remedies (not yet implemented)

1. **Parallelize judge calls** — 4 judges are independent; `ThreadPoolExecutor` could cut L2 block time by ~50-70% (vLLM concurrency permitting).
2. **Shrink L2 trigger surface** — Remove overly broad conditions:
   - `candidate_hints` symbolic risk: drop `"hidden"` / `"truth"` (too common)
   - `speak`/`observe_reaction`: only trigger if entity also in `visible_objects` (true ambiguity)
   - Remove backward compat assumption source check
3. **Batch judges into a single multi-task prompt** — One LLM call returning 4 verdicts. Longer prompt but eliminates roundtrip overhead.
4. **Selective re-check in repair loop** — Only re-run judges that previously failed, not all 4.
