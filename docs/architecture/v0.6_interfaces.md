# v0.6 Agentic Interfaces

Stable interfaces for the agentic pipeline. No agent prompt change should alter these schemas without updating this doc and tests.

---

## 1. StoryPacket

**Purpose:** Turn code-owned world state into LLM-usable local context.

**Producer:** `story_packet.build_story_packet(world: WorldState) -> dict`

**Consumer:** Writer, Translator, Hard Auditor

### Schema

```python
{
  "scene": {
    "location": str,              # player current location
    "visible_entities": [str],    # always includes "player" + nearby NPCs
    "visible_objects": [str],     # objects at location + player inventory
    "atmosphere": str,            # qualitative mood description
  },
  "player_context": {
    "known_facts": [str],         # visible facts involving player
    "recent_events": [str],       # last N events (facts, knowledge, turn log)
    "inventory_or_handheld": [str],
  },
  "npc_surface": {
    "<npc_id>": {
      "role": str,
      "visible_mood": [str],      # qualitative only (warm, reserved, etc.)
      "can_speak": bool,
      "_auditor_relations": {str: float},  # debug numbers, auditor only
    }
  },
  "allowed_effect_kinds": [str],  # closed set, context-dependent
  "allowed_reveals": [str],       # facts NPCs may mention in speech
  "forbidden": {
    "entities_not_present": [str],
    "hidden_fact_aliases": [str],
    "forbidden_narration": [str],  # e.g. "npc_inner_thought_hidden_fact"
  },
  "auditor_only": {
    "hidden_truths": [{"predicate": str, "args": [...], "alias": str}],
    "active_hooks": [{"id": str, "type": str, "owner": str, ...}],
    "all_beliefs": [{"id": str, "description": str, "prob": float}],
  },
}
```

### Visibility Rules

| Tier | In Packet | Example |
|------|-----------|---------|
| visible_to_player | `scene`, `npc_surface.visible_mood` | location, entities, atmosphere |
| known_to_npc | `npc_surface.role` | barkeep, guard |
| hidden_truth | `auditor_only.hidden_truths` | secret locations, motifs |

Writer-facing packet **must not expose**:
- belief probabilities
- debug IDs
- hidden facts
- raw internal event names

## 2. WriterOutput

**Purpose:** LLM-generated narrative segments + proposed world changes.

**Producer:** `writer_agent.run_writer(story_packet, player_input) -> WriterOutput`

**Consumer:** Translator, Scanner, Hard Auditor, Committer

### Schema

```python
@dataclass
class WriterOutput:
    interpretation: str = ""           # LLM reading of player intent
    segments: list[Segment] = []       # player-facing narrative pieces
    candidate_patch: list[CandidatePatchEffect] = []
    assumptions: list[dict] = []       # writer's declared assumptions
    risk_notes: list[str] = []         # writer-flagged concerns
    raw_json: dict | None = None       # original LLM response

@dataclass
class Segment:
    id: str                            # e.g. "s1", "s2"
    type: str                          # player_action, npc_observable_reaction, ...
    text: str                          # player-facing prose
    patch_refs: list[str] = []         # which patch effects this segment supports
    declared_claims: list[str] = []    # claim kinds writer thinks this contains
    transient_only: bool = False       # if true, no patch_refs allowed

@dataclass
class CandidatePatchEffect:
    kind: str                          # closed set (see below)
    args: dict = {}
```

### Valid Effect Kinds (closed set)

```text
transient_event
journal_note
observe_reaction
knowledge_transfer
relation_delta
belief_delta
move
add_fact
remove_fact
create_hook
consume_item
acquire_item
risk_flag
reveal
```

## 3. NarrativeClaim

**Purpose:** Structured extraction of what the narrative text claims happened.

**Producer:** `translator_agent.run_translator(segments, story_packet) -> list[NarrativeClaim]`

**Consumer:** Hard Auditor

### Schema

```python
@dataclass
class NarrativeClaim:
    segment_id: str
    kind: str                          # closed set (see below)
    subject: str | None = None         # entity performing action
    action: str | None = None          # verb
    target: str | None = None          # entity acted upon
    evidence_span: str = ""            # exact quoted text basis
    confidence: float = 0.0            # 0.0–1.0
    metadata: dict = {}                # kind-specific extras
```

### Claim Kinds (closed set)

```text
player_action
player_speech
player_memory_or_journal
npc_speech
npc_offer
npc_observable_action
npc_observable_reaction
npc_inner_state
ambient_entity_action           # unnamed background entities
named_entity_action
object_state
location_state
prop_usage
unregistered_prop_usage
knowledge_claim
hidden_fact_reference
world_state_change
concrete_affordance_creation
uncertain_inference
remote_event
raw_debug_exposure
```

### Rules

- Over-extract rather than under-extract.
- Do NOT merge multiple events into one claim.
- Every claim MUST have an `evidence_span`.
- Translator does NOT judge validity — only extracts.

## 4. AuditIssue

**Purpose:** Record a single audit finding with severity, type, and repair instruction.

**Producer:** Hard Auditor, Soft Auditor, Editor

**Consumer:** Scorecard, Editor, Runner

### Schema

```python
@dataclass
class AuditIssue:
    severity: str           # hard_fail | medium_issue | soft_issue
    type: str               # closed set per auditor
    segment_id: str | None = None
    evidence: str = ""
    reason: str = ""
    repair_instruction: str = ""
```

### Severity Definitions

| Severity | Meaning | Blocks Commit? |
|----------|---------|----------------|
| `hard_fail` | Unsupported story consequence or rule violation | Yes (only safe effects admitted) |
| `medium_issue` | Risky concrete assumption | No, but may trigger repair |
| `soft_issue` | Tone, fit, continuity, texture | No, affects experience score |

### Hard Auditor Issue Types

```text
hidden_fact_leak
absent_entity_action
remote_event_claim
raw_debug_exposure
invalid_effect_kind
state_change_without_support
npc_speech_without_patch_support
npc_offer_without_patch_support
patch_without_support
locked_fact_contradiction
```

### Medium Issue Types

```text
unregistered_concrete_prop
```

### Soft Auditor Issue Types

```text
too_mechanical
debug_tone
repetition
overdramatized_reaction
underspecified_feedback
style_drift
weak_player_feedback
```

## 5. RewriteTask

**Purpose:** Localized repair instruction from Editor to Writer.

**Producer:** `editor_agent.run_editor(segments, issues, admitted_patch) -> list[RewriteTask]`

**Consumer:** Repair loop / Runner

### Schema

```python
@dataclass
class RewriteTask:
    segment_id: str
    operation: str              # replace | delete | insert_after
    severity: str               # hard_fail | medium_issue | soft_issue
    reason: str = ""
    keep_context_segments: [str] = []
    allowed_patch_refs: [str] = []
    instruction: str = ""       # natural language rewrite direction
```

### Rules

- Prefer local repair over full rewrite.
- Preserve passing segments. Do not touch them.
- Do not alter admitted patch unless patch itself failed.
- If patch failed, request patch + affected segment rewrite.
- If only prose failed, request narrative-only rewrite.

## 6. AdmittedPatch (TurnDraft)

**Purpose:** Full lifecycle record of one turn, from input to committed state.

**Producer:** Runner (`play_agentic.py`, `agentic_5turn_smoke_test.py`)

**Consumer:** Committer, Persistence layer, Eval harness

### TurnDraft Schema

```python
@dataclass
class TurnDraft:
    draft_id: str
    player_input: str = ""
    pre_world_ref: str = ""
    story_packet: StoryPacket | None = None
    writer_output: WriterOutput | None = None
    translated_claims: list[NarrativeClaim] = []
    deterministic_scan: dict = {}
    hard_audit: dict = {}
    soft_audit: dict = {}
    editor_tasks: list[RewriteTask] = []
    rewrite_history: list[dict] = []
    final_segments: list[Segment] = []
    candidate_patch: list[CandidatePatchEffect] = []
    admitted_patch: list[CandidatePatchEffect] = []
    post_world_ref: str = ""
    player_output: str = ""
    scorecard: dict = {}
```

### Persistence Rules

- Every turn MUST be written as `turn_NNN.json`.
- Failed turns MUST be written as `turn_NNN_error.json`.
- Error turns MUST include: `error_stage`, `error_type`, `error_message`, `error_traceback`.
- Raw model output MUST be preserved in error turn artifact when available.

## 7. Scorecard

**Purpose:** Quantitative turn-level and run-level evaluation.

**Producer:** Runner

**Consumer:** Eval harness, summary generator

### Schema

```python
@dataclass
class TurnScorecard:
    turn_id: str = ""
    grounding_score: float = 0.0
    patch_alignment_score: float = 0.0
    hidden_leak_count: int = 0
    absent_entity_action_count: int = 0
    raw_debug_exposure_count: int = 0
    unsupported_claim_rate: float = 0.0
    unregistered_state_change_count: int = 0
    action_understanding_score: float = 0.0
    rewrite_locality_score: float = 0.0
    player_experience_score: float = 0.0
    repair_rounds: int = 0
    token_cost_estimate: int = 0
    latency_ms: int = 0
    hard_failures: list[str] = []
    medium_issues: list[str] = []
    soft_issues: list[str] = []
    hard_issue_count: int = 0
    medium_issue_count: int = 0
    soft_issue_count: int = 0
    notes: list[str] = []
    missing_player_output: bool = False
    missing_turn_sequence: bool = False
    state_continuity_score: float = 0.0
    packet_support_score: float = 0.0
```

### Scoring Rules

| Condition | Effect |
|-----------|--------|
| `hard_failures` non-empty | `acceptable = false`, `player_experience_score = 0.0` |
| `medium_issues` non-empty | `player_experience_score` capped at 0.75 |
| `soft_issues` non-empty | `player_experience_score` capped at 0.85 |
| `missing_player_output = true` | `player_experience_score = 0.0` |

## 8. Pipeline Flow

```text
WorldState
    |
    v
StoryPacketBuilder  -->  StoryPacket
    |
    v
Writer (LLM)        -->  WriterOutput (segments + candidate_patch)
    |
    +---> Translator (LLM)  -->  NarrativeClaims
    |                           |
    +---> Scanner (code)    -->  ScannerFindings
                                |
                                v
                          Hard Auditor (code)
                                |
                    +--passed--> Soft Auditor (LLM)
                    |              |
                    |              +--> Editor (LLM) --> RewriteTasks
                    |                                   |
                    +-----------------------------------+
                    |
                    v
              Committer  -->  WorldState' (mutated)
                    |
                    v
              Scorecard + TurnDraft (persisted)
```

Narrative alone cannot mutate state. Only Committer can.
